# Portfolio Website

A responsive, dark-themed personal portfolio in plain HTML and CSS. No build step and no dependencies.

## Customize
Open `index.html` and edit the name, about text, skills and contact links to match you (add your LinkedIn and email when you are ready).

## Host it free with GitHub Pages
1. Push this folder to a repo named `portfolio-website` (or `Denwin437.github.io`).
2. In the repo go to Settings → Pages, choose the `main` branch and the root folder, and save.
3. Your site goes live at `https://Denwin437.github.io/portfolio-website/`.

## What I practiced
Semantic HTML, CSS custom properties, CSS Grid and Flexbox, responsive design without media queries, and basic SEO meta tags.
