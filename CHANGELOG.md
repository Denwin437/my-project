# Changelog

All notable changes are listed here. Format based on [Keep a Changelog](https://keepachangelog.com).

## [1.0.1] - 2026-11-07
### Security
- URL shortener: debug mode is now off by default and the server binds to 127.0.0.1.
- CI: added bandit and pip-audit scans.

## [1.0.0] - 2026-11-07
### Added
- Eight projects: url-shortener, markdown-converter, log-analyzer, password-toolkit,
  task-tracker-cli, expense-tracker, text-analyzer and portfolio-website.
- 49 unit tests, a GitHub Actions workflow with linting and a Python 3.10 / 3.12 test matrix.
- Security policy, contributing guide, issue and pull request templates, Dependabot config.
